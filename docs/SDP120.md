# Strich SDP-120 digital piano

REAPER lists it under the generic name **General MIDI** (its USB-MIDI interface carries no product name). No MIDI
implementation is published; everything below was measured on the instrument on 2026-09-04 with REAPER's
recent-input buffer while pressing each panel control.

## What it sends

| Action on the piano | Messages |
|---|---|
| Constantly, once a second | sysex `F0 33 00 F7`. 0x33 is Clavia's registered manufacturer ID, reused here as a keep-alive for the wireless companion app. Cannot be disabled on the piano |
| Sustain pedal | CC 64, 64 / 0, on channel 1, repeated on channels 6 and 16 |
| Sostenuto pedal | CC 66, 64 / 0, same channels |
| Soft pedal | CC 67, 64 / 0, same channels |
| Tone change | bank select CC 0 and a program change on **channel 16**, plus CC 64 = 0 resets on channels 2-15 |
| Metronome | notes 75 / 76 on channel 10, preceded by CC 10 (pan) each tick |
| Keys | notes with velocity on channel 1. TRANSPOSE is applied to the MIDI output (transpose +1 turns middle C into note 61). Touch dynamics "off" sends a fixed velocity of 125 |
| SUSTAIN button | CC 64 = 100 (the pedal sends 64) on channels 1, 6 and 16 |
| DRUM mode | the keys move to **channel 10** as drum notes (no note-offs), the same channel as the rhythm and metronome |
| SPLIT | the left half plays on **channel 16** (bank select + program change on 16 when switched on); the right half stays on channel 1 |
| Dual (SET UP dUL) | the layer voice is repeated on **channel 6** (program change on 6 when switched on) |
| CHORD mode | chord keys still send their notes on channel 1 while the accompaniment plays |
| VOLUME buttons, SELECT, TEMPO, MP3 buttons | nothing (volume is local; the +/- buttons change the tone number instead) |
| Rhythm start | RPN pitch-bend-range setup, then the full accompaniment as MIDI: drums on channel 10, parts with program changes on channels 11-15 |
| Demo song | the whole song as multi-channel MIDI playback: program changes and notes on channels 2, 4, 5, 8-12, 15 |
| Record button | nothing |
| Reverb change | CC 91 on channels 1, 2, 6, 16 and a Roland GS sysex `F0 41 00 42 12 40 01 30 <type> <sum> F7` |
| Chorus change | CC 93 on channels 1-16 |
| Most panel actions | a burst of CC 64 = 0 on channels 2-15 |
| MIDI clock | none |

## Panel and settings (from the manual)

The printed manual (a generic "Multi-function 88 Keys Electronic Keyboard" booklet shared with other pianos on the same
platform, e.g. the Fesley FEP160 and Torrins 88005C with the same 900-tone / 700-rhythm / 110-song feature set)
lists these controls: START/STOP, DEMO ALL, TONE, RHYTHM, number keys 0-9 with + / -, SELECT, VOLUME, TRANSPOSE,
TEMPO, SUSTAIN, SET UP/DYNAMIC, SPLIT, DRUM, CHORD, REC, PLAY, MP3 prev/next and MP3 play/pause. A short press of
SET UP/DYNAMIC cycles through dUL (dual tone on/off), rEU (reverb), cho (chorus), tUn (fine tune), trS
(transpose), d-U (dual volume), L-U (left volume), S-P (split point), C-P (chord point) and inS (minus-one
practice); a long press sets touch dynamics (light / moderate / heavy / off). There is no MIDI page at all: no
local control, no transmit channel, no clock setting. The keep-alive sysex is the handshake for the phone app the
manual refers to ("open the app and select Bluetooth connection"); it cannot be switched off from the panel, so
filtering on the REAPER side is the only fix.

## What it means for REAPER

Any track set to "all MIDI inputs" hears all of this: the metronome and rhythms play your drum instruments, the
keep-alive fills the recent-input list, GS sysex reaches synths. The cure is the ReaLearn unit
`realearn/presets/main/sdp120/filter.preset.luau` on the piano's device: it matches the unwanted messages into a
dummy target and ReaLearn does not pass matched events on to tracks. Flags at the top of the preset choose what
to swallow (keep-alive, metronome, rhythm and demo parts on channels 2-5 and 7-15, GS sysex, pedal duplicates);
channel 1 (keys), channel 6 (dual layer) and channel 16 (split left half, tone changes) always pass. DRUM mode is the one casualty: it plays on channel 10, so set `rhythm = false` and `metronome = false` if you want drum-mode keys in REAPER. The
first-time setup adds the unit when a device named `General MIDI` exists (`SDP120_INPUT_NAME` in the script).
The unit's entry in `controllers.json` carries the piano's output port as well as its input: ReaLearn 2.18 silently
skips a managed controller that has only an input port, so an input-only entry looks fine and filters nothing. The
file is read at REAPER start only; a change needs a restart.

## The piano in the MIDI Control Center

The editor has an **SDP-120** device (Device switch at the top). Its section of `model.json` drives the same
ReaLearn unit, generated on Apply from `midi_control_center/sdp120_interpreter.luau` (the hand-written
`filter.preset.luau` in this repo is the starting point until the first Apply):

- **Filter** - one checkbox per class of unwanted message (keep-alive, metronome, rhythms and demos, GS sysex,
  panel resets, tone changes, pedal duplicates). DRUM mode plays on channel 10, so switch the metronome and
  rhythm flags off if you want drum-mode keys in REAPER.
- **Number entry** - the piano's tone selection is the one rich control it has. Typing a number in TONE mode
  sends program change `number - 1` on channel 1 (bank select is always 0), so **display 001-128 are 128
  distinct triggers**; 129 and up alias onto them (899 sends the same as 003). The unit swallows the program
  change so instruments never see it and re-injects the number as CC 20 on channel 14 into the piano's own
  input; the background watcher (`Oxygen Pro - Live watcher.lua`, module `sdp120_numbers.lua`) reads that echo
  and performs the assigned entry: **add an FX by name** to the selected track, a new track or track 1
  (optionally opening its window or reusing an existing instance), or **run a REAPER action**. Verified on
  hardware 2026-09-04: 001 added ReaEQ, 002 ReaComp, 003 inserted a track.
- **Panel triggers** - the split voice switch (program change on channel 16) and the dual voice switch (program
  change on channel 6) can each fire a REAPER action. The SUSTAIN button is deliberately not offered: it does
  work as a trigger (CC 64 = 100 on channels 1, 6 and 16, distinguishable from the pedal's 64) but it also latches
  the piano's own sustain, and nothing REAPER sends can release that.

The volume buttons, SELECT, TEMPO, START/STOP and the MP3 buttons send nothing usable; rhythm and song numbers
send nothing at all. The pedals are left as pedals.
