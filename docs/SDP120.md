# Strich SDP-120 digital piano

REAPER lists it under the generic name **General MIDI** (its USB-MIDI interface carries no product name). No MIDI
implementation is published; everything below was measured on the instrument on 2026-09-04 with REAPER's
recent-input buffer while pressing each panel control.

## What it sends

| Action on the piano | Messages |
|---|---|
| Constantly, once a second | sysex `F0 33 00 F7`. 0x33 is Clavia's registered manufacturer ID, reused here as a keep-alive for the wireless companion app. Cannot be disabled on the piano |
| Sustain pedal | CC 64, 64 / 0, on channel 1, repeated on channels 6 and 16 |
| Sostenuto pedal | CC 66, 64 / 0, same channels |
| Soft pedal | CC 67, 64 / 0, same channels |
| Tone change | bank select CC 0 and a program change on **channel 16**, plus CC 64 = 0 resets on channels 2-15 |
| Metronome | notes 75 / 76 on channel 10, preceded by CC 10 (pan) each tick |
| Keys | notes with velocity on channel 1 |
| Rhythm start | RPN pitch-bend-range setup, then the full accompaniment as MIDI: drums on channel 10, parts with program changes on channels 11-15 |
| Demo song | the whole song as multi-channel MIDI playback: program changes and notes on channels 2, 4, 5, 8-12, 15 |
| Record button | nothing |
| Reverb change | CC 91 on channels 1, 2, 6, 16 and a Roland GS sysex `F0 41 00 42 12 40 01 30 <type> <sum> F7` |
| Chorus change | CC 93 on channels 1-16 |
| Most panel actions | a burst of CC 64 = 0 on channels 2-15 |
| MIDI clock | none |

## What it means for REAPER

Any track set to "all MIDI inputs" hears all of this: the metronome and rhythms play your drum instruments, the
keep-alive fills the recent-input list, GS sysex reaches synths. The cure is the ReaLearn unit
`realearn/presets/main/sdp120/filter.preset.luau` on the piano's device: it matches the unwanted messages into a
dummy target and ReaLearn does not pass matched events on to tracks. Flags at the top of the preset choose what
to swallow (keep-alive, metronome, rhythm and demo parts on channels 2-5 and 7-15, GS sysex, pedal duplicates);
channel 1 (keys), channel 6 and channel 16 (layer / split voices and tone changes) always pass. The
first-time setup adds the unit when a device named `General MIDI` exists (`SDP120_INPUT_NAME` in the script).

As a control surface the piano offers little: no buttons send anything on their own except the tone buttons
(program change on channel 16, 0-199), which a ReaLearn mapping can use as 200 numbered triggers, and the three
pedals, which are ordinary CCs on channel 1.
