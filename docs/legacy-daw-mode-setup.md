# Oxygen Pro 61 + ReaLearn — what is built and what is left to click

> **New machine or fresh keyboard:** run `Scripts/MIDI Control Center/MIDI Control Center - Setup.lua` from REAPER's
> Actions list. It finds the device numbers, rewrites `controllers.json` and the preset's drum-injection device,
> adds Helgobox to the monitoring FX chain and lists the three preference boxes to tick. Then restart REAPER.
> No Python is needed any more; the watcher is a ReaScript started by `__startup.lua`.

> **2026-09-03, later:** the design moved to the keyboard's Live firmware mode with ONE ReaLearn unit
> (`oxygen-pro-61/live`). Read `LIVE_MODE_MAP.md` for the current layout. The steps below still apply
> except: the User DAW "REALRN" no longer matters (the watcher puts the keyboard into Live mode), and
> `controllers.json` now names the `live` preset for port 3. The DAW-mode version is kept in
> `backup-2026-09-03-dawmode/`.
> **MIDI Devices for Live mode:** `MIDIIN3 (Oxygen Pro 61)` must be **control-only** (enable input for
> control messages, disable it as a track input) so pad notes and CCs never reach a track. Drum-mode pads
> are re-injected by ReaLearn into the `Oxygen Pro 61` (port 1) input on channel 10.

Built on 2026-09-03. Layout: `OXYGEN_PRO_61_MAP.md`. Facts behind every choice: `reaper` skill FINDINGS F-0011..F-0018.

## Keyboard (once)

1. Hold **DAW**, scroll to **User DAW**, press the encoder.
2. In the Preset Editor: File > Load Preset > `REALRN.OxygenPro61DawPreset`, then File > Send Preset > **RAM** > Send.
3. On the keyboard: **SHIFT + DAW** (edit), press **DAW**, choose **Replace** (or Save As "REALRN").
4. Hold DAW again and confirm "REALRN" is the active DAW preset.

## REAPER (once)

1. Preferences > MIDI Devices:
   - `MIDIIN3 (Oxygen Pro 61)`: enable input **and** control. `MIDIOUT3 (Oxygen Pro 61)`: enable output.
   - `Oxygen Pro 61`: enable input and control (pads must reach ReaLearn and LoopCanvas bindings).
   - Leave MIDIIN2/MIDIIN4/MIDIOUT2/MIDIOUT4 disabled.
2. Preferences > Control/OSC/web: **remove** the Mackie Control Universal entry (it would fight ReaLearn for port 3).
3. Actions > Load ReaScript > `Scripts/MIDI Control Center/Oxygen Pro - Setup ReaLearn.lua`, run it.
   In the ReaLearn window that opens: **Menu > Instance > Enable global control**. Two units appear with their presets.
4. Restart REAPER once so `__startup.lua` starts the watcher (or run `Oxygen Pro - LED unlock.lua`).

## Checks

- Select mode: click tracks in REAPER, buttons follow. Press a Mute-row button once, LEDs switch to showing mutes.
- Bank 1 pads: blue at rest, green/yellow/red by hit strength.
- Bank > then hit any pad: the bank-2 colours (green / azure) appear; pads 1-8 fire LoopCanvas press slots.

## Known limits

- The keyboard never reports Mode-button changes; LEDs show the state of the last mode you pressed a button in.
- Pad colours for banks 2-4 repaint on the first pad hit after switching bank (bank buttons live on port 3, pads on port 1).
- Transport `<<` / `>>` are wired to REAPER actions 40042 / 40043 (go to start / end). Verify those IDs in the Actions window.
- If a ReaLearn unit does not appear, check the device indices in `controllers.json` against Preferences > MIDI Devices
  (input 16 = MIDIIN3, input 14 = Oxygen Pro 61, output 16 = MIDIOUT3 on this machine; they can shift when devices change).
