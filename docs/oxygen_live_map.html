Knob functions (Shift + pad 9 / 10 / 11): Pan · Device = focused FX parameters 1-8 · Send 1 of each track; a fourth, sends 1-8 of the selected track, answers CC 83 if any button sends it. Fader 9 is always master volume. Faders and knobs pick up, so a control does nothing until it passes the current value. Function buttons are latching; one press toggles. Select buttons add and remove tracks from the selection.

Pad modes, by layout (DAW button toggles the layout)

#General DAW (shipped layout)
1Drums: hits are re-emitted into the Oxygen Pro 61 port-1 input as channel-10 notes 36-51, so drum tracks keep their usual input; blue at rest, soft medium hard
2Mixer tracks 1-8: pads 1-8 mute muted / open; pads 9-16 solo on / off
3Mixer tracks 9-16, same colours

5Free: white, nothing mapped

On each DAW press the pads sweep in the layout's colour (green for General DAW) for a second, then return to their real colours. Add layouts and pad modes in the editor. The marker and utility action IDs are REAPER defaults; confirm them once in the Actions window.

Keyboard side

Back layer (press Back, then the button · REAPER only)

The keyboard reports nothing for a second button while any button is held (measured 2026-09-03), so no button can be a hold-modifier. Instead Back (CC 104) arms a one-shot layer: press Back, the pads switch to a violet/rose checkerboard, then press the control. That press fires the function and drops the layer (pads repaint). Press Back again to cancel. Turning the encoder keeps the layer armed until the next press.

Tempotap sets the keyboard's tempo only; the button sends nothing to the computer and the keyboard emits no MIDI clock in Internal mode (measured). Keep Clock = External so the arpeggiator and Note Repeat follow REAPER's tempo while REAPER plays; they pause while REAPER is stopped because REAPER only sends clock during playback. Behind the panel

How it stays alive

  • The keyboard runs in its Ableton "Live" firmware mode. Nothing is stored on the keyboard; the ReaScript Oxygen Pro - Live watcher.lua, started by __startup.lua, switches it into Live mode and unlocks the LEDs when REAPER starts and after every keyboard power-on, then asks ReaLearn to repaint. No Python required.
  • One ReaLearn unit does everything: presets/main/oxygen-pro-61/live.preset.luau on MIDIIN3 (control-only) / MIDIOUT3, created automatically from Helgoboss/ReaLearn/controllers.json.
  • The screen keeps saying Ableton: nothing arriving from the host redraws it in this mode. The pad sweep is the layout indicator.
  • New machine: run Scripts/MIDI Control Center/MIDI Control Center - Setup.lua. oxygen_led_unlock.py --restore returns the keyboard to its normal presets.

Where the pieces live

  • DAW/Utility/oxygen-pro-tools/: LIVE_MODE_MAP.md, SETUP_STEPS.md, scripts, and dated backups of both the Live-mode and the earlier DAW-mode setups.
  • REAPER/Scripts/MIDI Control Center/: the watcher, the first-time setup, the manual unlock and a one-shot flash test.
  • Every measurement behind these choices is in the reaper skill's FINDINGS, F-0011 through F-0023. Keyboard-side facts come from the Oxygen Pro Series User Guide v1.1.

Pad colours are the keyboard's fixed palette. A lit button on this diagram means REAPER says that state is on. Blue labels are the keyboard's own functions; amber labels are Shift combinations; violet labels are Back-layer functions (press Back on the keyboard, or click it here).
